# 💰 한탕의 꿈 (Team.Exit-0)

터미널 기반 멀티플레이어 게임 **"한탕의 꿈"** 은 노동과 도박을 통해 자산을 벌거나 잃으며, 랭킹 경쟁까지 가능한 클라이언트-서버 기반 게임입니다.  
소켓 통신과 `fork()`, `파일 입출력`, `ncurses` 등 다양한 시스템 프로그래밍 기술이 활용되었습니다.

> 본 프로젝트는 시스템 프로그래밍 수업 **ELEC462** 의 팀 프로젝트로 진행되었습니다.

---

## 📦 프로젝트 설치 및 실행 방법

### 1. Clone Repository

```bash
git clone https://github.com/elec462-team2/exit0-game.git
cd exit0-game
```

### 2. Build

```bash
make clean
make
```

### 3. 실행

#### 서버 실행

```bash
./server_exec 9190
```

#### 클라이언트 실행

```bash
./client_exec 127.0.0.1 9190
```

> ⚠️ 서버를 먼저 실행한 후, 클라이언트를 실행해야 합니다.

> ⚠️ **서버 포트가 이미 사용 중일 경우**, 다른 포트 번호를 사용하세요.<br> 예: `9191`, `9000`, `1234` 등


---

## 🕹️ 프로젝트 사용 방법

### 1. 로그인 및 회원가입
- 클라이언트 실행 후 게임 시작하기
- 회원가입 또는 로그인 진행
- 아이디 중복 검사 포함
- 로그인 성공 시 메인 메뉴로 이동

### 2. 메인 메뉴
-  🎰 카지노 입장: 하이 앤 로우, 블랙잭, 경마 게임 중 선택하여 플레이 가능
-  🏗️ 노동장 입장: 햄버거 만들기 아르바이트, 택배 분류 아르바이트 중 선택하여 플레이 가능
-  🏆 랭킹 보기: 상위 랭커 10명 확인 가능
-  💬 메신저: 게임 이용자들과 메세지 주고 받기 가능
-  🔚 종료: 로그아웃 및 종료

### 3. 게임 시스템
- 터미널 UI(TUI) 기반의 실시간 입력 처리
- 게임 결과는 서버에서 계산 후 클라이언트에 전달
- 자산은 종료 후에도 서버(asset_db.txt)에 저장되며 재접속 시 복구
