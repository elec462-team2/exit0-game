# 💰 한탕의 꿈 (Exit0 Game)

터미널 기반 멀티플레이어 게임 **"한탕의 꿈"** 은 노동, 카지노, 랭킹 시스템 등을 포함한 클라이언트-서버 구조의 소켓 통신 기반 게임입니다. 플레이어는 게임을 통해 자산을 획득하거나 잃을 수 있으며, 랭킹 시스템을 통해 다른 유저들과 경쟁할 수 있습니다.

본 프로젝트는 시스템 프로그래밍 수업의 팀 프로젝트로 진행되었으며, `fork()`, `socket`, `파일 입출력`, `ncurses` 등 다양한 시스템 프로그래밍 기술이 활용되었습니다.

---

## 📦 프로젝트 설치 및 실행 방법

### 1. Clone Repository

```bash
git clone https://github.com/elec462-team2/exit0-game.git
cd exit0-game
```

### 2. Build

#### make clean

```bash
make clean
```

#### make

```bash
make
```

### 3. 실행

#### 서버 실행

```bash
./server_exec 9190
```

#### 클라이언트 실행

```bash
./client_exec 127.0.0.1 9190
```

> ⚠️ 서버를 먼저 실행한 후, 클라이언트를 실행해야 합니다.

---

## 🕹️ 프로젝트 사용 방법

### 1. 로그인 및 회원가입
- 클라이언트 실행 후 '게임 시작하기' 선택
- 회원가입 또는 로그인 진행
- 아이디 중복 검사 포함
- 로그인 성공 시 메인 메뉴로 이동

### 2. 메인 메뉴
-  카지노 입장: 하이 앤 로우, 블랙잭, 경마 게임 중 선택하여 플레이 가능
-  노동장 입장: 햄버거 만들기 아르바이트, 택배 분류 아르바이트 중 선택하여 플레이 가능
-  랭킹 보기: 상위 랭커 10명 확인 가능
-  메신저: 게임 이용자들과 메세지 주고 받기 가능
-  로그아웃 및 종료

### 3. 게임 시스템
- 카지노, 노동장: 실시간 입력 기반의 터미널 UI(TUI)
- 게임 결과는 서버에서 계산, 자산 자동 반영 후 클라이언트로 전송
- 자산은 종료 시 서버에 저장됨 (`asset_db.txt`) > 재입장 시 저장된 자산 불러옴
